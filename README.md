# RAG-Demo：基于 BGE 与 ChromaDB 的知识库检索系统

## 1. 项目介绍

本项目是一个基于 Python 的 RAG 检索系统实践项目，主要实现本地文档入库、向量检索、文档生命周期管理和检索效果评估。

项目使用 BGE Embedding 模型将文本转换为语义向量，通过 ChromaDB 实现向量存储与相似度检索，并使用 SQLite 管理文档信息，实现重复检测和文档更新。

目前项目重点完成 RAG 的文档处理与检索环节，尚未接入大语言模型进行最终答案生成。

## 2. 核心功能

- **文档读取：** 加载本地文档。
- **文本切分：** 将长文本切分为适合检索的 Chunk。
- **Embedding：** 使用 `BAAI/bge-small-zh-v1.5` 将文本转换为向量。
- **向量存储：** 使用 ChromaDB 保存文档向量及元数据。
- **相似度检索：** 根据查询检索相关文档片段。
- **文档管理：** 使用 SQLite 管理文档信息，支持重复检测和内容变更识别。
- **版本维护：** 文档更新后重新生成向量，并删除旧版本 Chunk。
- **检索评估：** 使用 Precision@K、Recall@K、F1@K、RR 和 MRR 评估检索效果。

## 3. 技术栈

| 技术 | 用途 |
|---|---|
| Python | 项目开发 |
| Sentence Transformers | 加载和使用 Embedding 模型 |
| BAAI/bge-small-zh-v1.5 | 中文文本向量化 |
| ChromaDB | 向量存储与检索 |
| SQLite | 文档元数据与生命周期管理 |
| NumPy | 向量及数值计算 |

## 4. 系统架构

```text
本地文档
   ↓
文档读取
   ↓
文本切分
   ↓
BGE Embedding
   ↓
ChromaDB 向量存储
   ↓
用户查询
   ↓
查询向量生成
   ↓
向量相似度检索
   ↓
返回相关文档片段
   ↓
检索效果评估
```

文档管理通过 SQLite 独立维护文档注册信息和处理状态。

## 5. 文档生命周期管理

使用 SQLite 管理文档信息：

1. 首次导入：计算文件 Hash，创建文档记录。
2. 重复导入：识别内容未变化的文档，避免重复处理。
3. 文档更新：检测文件内容变化，重新切分并生成 Embedding。
4. 版本维护：保存新版本向量，删除旧版本 Chunk。
5. 状态管理：记录文档处理状态。

## 6. 检索效果评估

构建独立的检索评估数据集，实现：

- Precision@K：检索结果的准确程度。
- Recall@K：相关文档的召回程度。
- F1@K：Precision 与 Recall 的综合指标。
- RR：单个查询的倒数排名。
- MRR：多个查询的平均倒数排名。

通过评估结果分析检索质量。

## 7. 项目运行

环境要求：Python 3.10。

安装依赖：

```bash
pip install -r requirements.txt
```

运行文档处理：

```bash
python main.py
```

运行检索评估：

```bash
python run_evaluation.py
```

首次运行时，程序会创建本地数据库和向量存储目录。
